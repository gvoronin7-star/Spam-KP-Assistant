## Запуск приложения

### Приложение не запускается

**Симптомы:** Ошибка при запуске `python run.py`

**Решения:**

1. **Проверьте Python версию:**
   ```bash
   python --version
   ```
   Должно быть Python 3.11+

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Проверьте логи:**
   ```
   data/app.log
   ```

4. **Запустите с диагностикой:**
   ```bash
   python run_now.py
   ```

### GUI не отображается в PowerShell

**Симптомы:** Окно не появляется, консоль зависает

**Решения:**

1. **Используйте pythonw:**
   ```bash
   pythonw run.py
   ```

2. **Или запустите через консоль:**
   ```bash
   cmd /c python run.py
   ```

### Ошибка PyQt6

**Симптомы:** `ModuleNotFoundError: No module named 'PyQt6'`

**Решение:**
```bash
pip install PyQt6>=6.4.0
```

## SMTP/IMAP проблемы

### Не удаётся подключиться к Gmail

**Симптомы:** Authentication failed

**Решения:**

1. **Используйте App Password, а не обычный пароль:**
   - Зайдите в [Google Account](https://myaccount.google.com/)
   - Безопасность → 2-шаговая аутентификация
   - Пароли приложений → Создать пароль
   - Скопируйте 16-значный пароль

2. **Проверьте настройки:**
   - SMTP: `smtp.gmail.com:465` (SSL)
   - IMAP: `imap.gmail.com:993` (SSL)

3. **Включите менее безопасные приложения (если нужно):**
   - Не рекомендуется, но иногда требуется

### Не удаётся подключиться к Yandex

**Симптомы:** Authentication failed

**Решения:**

1. **Используйте App Password:**
   - Зайдите в [Яндекс ID](https://id.yandex.ru/)
   - Безопасность → Пароли приложений
   - Создать пароль
   - Скопируйте пароль

2. **Проверьте настройки:**
   - SMTP: `smtp.yandex.ru:465` (SSL)
   - IMAP: `imap.yandex.ru:993` (SSL)

### Ошибка SSL/TLS

**Симптомы:** SSL certificate error

**Решения:**

1. **Проверьте порт:**
   - SSL: порт 465 (SMTP) или 993 (IMAP)
   - TLS: порт 587 (SMTP) или 143 (IMAP)

2. **Обновите OpenSSL:**
   ```bash
   pip install --upgrade pyOpenSSL
   ```

### Письма попадают в спам

**Симптомы:** Поставщики не получают письма

**Решения:**

1. **Увеличьте задержки между письмами:**
   - Минимум 15-30 секунд
   - Настройка в мастере рассылки

2. **Уменьшите лимиты:**
   - Максимум 50 писем в час
   - Максимум 200 писем в день

3. **Используйте несколько SMTP аккаунтов:**
   - Ротация аккаунтов

4. **Настройте SPF/DKIM:**
   - Для корпоративных доменов

## LLM проблемы

### ProxyAPI недоступен

**Симптомы:** Ошибка подключения к LLM

**Решения:**

1. **Проверьте API ключ:**
   ```env
   PROXYAPI_API_KEY=your_key_here
   ```

2. **Проверьте баланс:**
   - Зайдите в личный кабинет ProxyAPI

3. **Система автоматически переключится на keyword-based классификацию**

### Низкая точность классификации

**Симптомы:** LLM ошибается в категоризации

**Решения:**

1. **Увеличьте температуру:**
   - В настройках LLM установите temperature = 0.7

2. **Улучшите промпт:**
   - Добавьте больше примеров в профиль

3. **Проверьте confidence threshold:**
   - Если < 0.5, используется fallback на keywords

### Лимиты токенов превышены

**Симптомы:** Rate limit error

**Решения:**

1. **Увеличьте лимиты в `.env`:**
   ```env
   LLM_RPM=120
   LLM_RPH=2000
   LLM_TPM=20000
   ```

2. **Или подождите сброса периода**

## База данных

### Ошибка подключения к БД

**Симптомы:** Database locked, cannot connect

**Решения:**

1. **Закройте все экземпляры приложения**

2. **Удалите блокировку:**
   ```
   data/spam_kp_assistant.db-shm
   data/spam_kp_assistant.db-wal
   ```

3. **Перезапустите приложение**

### Потеря данных после обновления

**Симптомы:** После обновления пропали данные

**Решения:**

1. **Восстановите из резервной копии:**
   ```
   data/backup_guide.md
   ```

2. **Или из экспорта JSON:**
   - Меню → Файл → Импорт данных

3. **Для будущих обновлений:**
   - Всегда делайте экспорт перед обновлением

### Alembic миграции не применяются

**Симптомы:** Ошибка при миграции БД

**Решения:**

1. **Проверьте текущую ревизию:**
   ```bash
   alembic current
   ```

2. **Проверьте доступные миграции:**
   ```bash
   alembic history
   ```

3. **Примените миграции:**
   ```bash
   alembic upgrade head
   ```

4. **Если ошибка — откатитесь:**
   ```bash
   alembic downgrade -1
   ```

## GUI проблемы

### Окно не открывается

**Симптомы:** Приложение запускается, но окно не появляется

**Решения:**

1. **Проверьте логи:**
   ```
   data/app.log
   ```

2. **Запустите в консоли:**
   ```bash
   python run.py
   ```

3. **Сбросьте настройки GUI:**
   ```python
   # В консоли
   from gui.main_window import MainWindow
   # Удалите настройки в реестре/файле
   ```

### Поиск не работает

**Симптомы:** Поле поиска не фильтрует результаты

**Решения:**

1. **Нажмите Enter после ввода текста**

2. **Очистите поле и введите заново**

3. **Проверьте регистр (поиск регистронезависимый)**

### Экспорт не работает

**Симптомы:** Кнопка экспорта не реагирует

**Решения:**

1. **Проверьте права на запись в папку:**
   - Файл сохраняется в `data/export_*.json`

2. **Закройте файл, если он открыт в другом приложении**

3. **Проверьте свободное место на диске**

## Тесты

### Legacy тесты падают

**Симптомы:** `test_database.py` и `test_import.py` не проходят

**Решения:**

1. **Игнорируйте их (не блокируют production):**
   ```bash
   pytest tests/ -v --ignore=tests/test_database.py --ignore=tests/test_import.py
   ```

2. **Или исправьте (низкий приоритет):**
   - `test_database.py` — проблема с fixture `test_db`
   - `test_import.py` — тестовые данные

### Тесты не находят модули

**Симптомы:** `ModuleNotFoundError` в тестах

**Решения:**

1. **Запускайте из корня проекта:**
   ```bash
   cd spam_kp_assistant
   pytest tests/ -v
   ```

2. **Или установите пакет в develop mode:**
   ```bash
   pip install -e .
   ```

### Coverage низкий

**Симптомы:** Покрытие < 90%

**Решения:**

1. **Запустите все тесты:**
   ```bash
   pytest tests/ -v --cov=. --cov-report=html
   ```

2. **Откройте отчёт:**
   ```
   htmlcov/index.html
   ```

## 🆘 Частые вопросы

### Q: Где посмотреть логи?
**A:** `data/app.log`

### Q: Где хранятся вложения?
**A:** `data/attachments/`

### Q: Как сбросить все настройки?
**A:** Удалите `data/spam_kp_assistant.db` и перезапустите

### Q: Как изменить порт для GUI?
**A:** GUI использует локальный порт, изменение не требуется

### Q: Можно использовать в сети?
**A:** Да, но рекомендуется HTTPS и аутентификация

**A:**
1. Сделайте экспорт данных
2. Обновите зависимости: `pip install -r requirements.txt`
3. Примените миграции: `alembic upgrade head`
4. Запустите: `python run.py`
