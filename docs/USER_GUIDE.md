## Введение

### Что такое Spam KP Assistant?

Приложение для автоматизации получения коммерческих предложений (КП) от поставщиков телеком-услуг.

**Версия 2.1 — LLM генерация писем!** Все функции полностью реализованы и протестированы (305/306 тестов).

### Основные возможности:

- ✅ **Создание профилей** — описание услуг (интернет, АТС, выделенные линии)
- ✅ **Импорт контактов** — загрузка списка поставщиков из CSV/XLSX
- ✅ **Шаблоны писем** — автоматическая генерация запросов с переменными
- ✨ **LLM генерация писем** — автоматическое создание писем через AI (v2.1)
- ✅ **Массовая отправка** — рассылка по всем контактам с задержками и лимитами
- ✅ **Приём ответов** — автоматический сбор КП из почты через IMAP
- ✅ **LLM генерация писем** — автоматическое создание через AI (v2.1)
- ✅ **LLM-классификация** — сортировка ответов (КП/вопросы/отказы/спам)
- ✅ **Парсинг вложений** — извлечение данных из PDF/Excel/Word
- ✅ **Задачи оператору** — автоматическое создание с дедлайнами
- ✅ **Напоминания** — 2 шага (3 дня, 7 дней)
- ✅ **Планировщик** — фоновая проверка почты и автоматизация
- ✅ **Rule Engine** — настраиваемые правила обработки
- ✅ **Сравнение КП** — таблица предложений от разных поставщиков
- ✅ **Аналитика** — дашборд и метрики
- ✅ **Поиск и фильтрация** — во всех вкладках GUI
- ✅ **Экспорт/импорт** — резервное копирование JSON/XML

### Преимущества:

- 🚀 **Экономия времени** — автоматизация рутинных запросов (часы → минуты)
- 📊 **Централизация** — всё в одном месте (БД, переписка, задачи)
- 🔒 **Безопасность** — шифрование паролей (Fernet + Windows Credential Manager)
- 📈 **Масштабируемость** — от 1 до 1000+ контактов
- 🔄 **Отказоустойчивость** — Retry с exponential backoff для email
- ⚡ **Производительность** — Rate limiting для LLM, TTL-кэширование
- 📝 **Аудит** — полная история всех действий
- 🧵 **Email threading** — правильное связывание переписки
- 🚫 **Дедупликация** — защита от дубликатов писем
- 🗑️ **Автоочистка** — удаление данных старше 90 дней

## Быстрый старт

### 1. Первый запуск

При первом запуске автоматически откроется **демо-окно** с примерами.

**Запуск:**
```bash
python run.py
```

### 2. Создание первого профиля

1. Нажмите **➕ Новый профиль** (вверху)
2. Заполните 5 страниц мастера:
   - **Название и описание** — например, "Интернет-канал 100 Мбит/с"
   - **Технические параметры** — скорость, протокол, SLA
   - **Требования** — цена, сроки подключения
   - **Q&A пары** — для LLM-генерации ответов
   - **Вложения** — техзадание, схемы (опционально)
3. Нажмите **✓ Готово**

### 3. Импорт контактов

1. Подготовьте CSV файл:
   ```csv
   email,company,contact_person
   sales@example.com,ООО Пример,Иванов И.И.
   ```
2. Перейдите во вкладку **👥 Контакты**
3. Нажмите **📥 Импорт**
4. Настройте колонки (сопоставьте поля)
5. Проверьте предпросмотр
6. Нажмите **📥 Импортировать**

### 4. Создание шаблона

1. Перейдите во вкладку **📝 Шаблоны**
2. Нажмите **➕ Создать**
3. Заполните:
   - Название
   - Тема письма
   - Текст (Plain + HTML)
   - Переменные: `{{ company }}`, `{{ service_name }}`
4. Нажмите **👁️ Предпросмотр** — проверьте замену переменных
5. Нажмите **💾 Сохранить**

### 5. Настройка SMTP/IMAP

1. Перейдите во вкладку **⚙️ Настройки**
2. Нажмите **Настроить аккаунты**
3. Добавьте аккаунт:
   - Gmail: smtp.gmail.com:465 (App Password)
   - Yandex: smtp.yandex.ru:465 (App Password)
   - Mail.ru: smtp.mail.ru:465 (App Password)
4. Нажмите **🧪 Проверить** — тестирует подключение
5. Нажмите **💾 Сохранить** — пароли шифруются

### 6. Массовая рассылка

1. Нажмите **📧 Создать рассылку**
2. Выберите **профиль** и **шаблон**
3. Выберите **контакты** (или все)
4. Настройте **задержки** (5-30 сек между письмами)
5. Настройте **лимиты** (в час/в день)
6. Нажмите **🚀 Запустить**
7. Следите за прогрессом в диалоге отправки

### 7. Проверка входящих

1. Нажмите **📬 Проверить почту**
2. Приложение проверит IMAP и получит новые письма
3. **LLM-классификация** определит тип ответа (КП/вопрос/отказ/спам)
4. **Парсинг вложений** извлечёт данные из PDF/Excel/Word
5. **Задачи** создадутся автоматически для обработки

### 8. Просмотр переписки

1. Перейдите во вкладку **💬 Переписка**
2. Выберите диалог с поставщиком
3. Просмотрите историю сообщений
4. При наличии КП — откройте данные через **📊 Просмотр КП**

### 9. Работа с задачами

1. Перейдите во вкладку **✅ Задачи**
2. Отфильтруйте по статусу (новые/выполненные)
3. Выберите задачу и нажмите **✓ Выполнить**
4. Задача помечается выполненной

### 10. Поиск и фильтрация

**Во всех вкладках:**
- Используйте **поле поиска** для быстрого поиска
- Применяйте **фильтры** по статусу, дате, профилю
- Сортируйте списки по клику на заголовки

### 11. Экспорт данных

1. **Меню → Файл → Экспорт данных**
2. Выберите формат (JSON или XML)
3. Выберите сущности (профили, контакты, шаблоны и т.д.)
4. Сохраните файл для резервного копирования

## Профили закупок

### Что это?

Профиль описывает, какую именно телеком-услугу вы запрашиваете.

### Структура профиля:

```
┌─────────────────────────────────────────┐
│ Название: Интернет-канал 100 Мбит/с    │
│ Описание: Запрос для офиса на 50 мест  │
├─────────────────────────────────────────┤
│ Технические параметры:                  │
│ • Скорость: 100 Мбит/с                  │
│ • Протокол: Ethernet                    │
│ • SLA: 99.9%                            │
├─────────────────────────────────────────┤
│ Требования:                             │
│ • Цена: до 50 000 руб/мес              │
│ • Срок: до 30 дней                      │
│ • Оборудование: оптический модуль      │
├─────────────────────────────────────────┤
│ Q&A пары (для LLM):                     │
│ Q: Какие цены?                          │
│ A: Просим предоставить стоимость       │
├─────────────────────────────────────────┤
│ Вложения:                               │
│ • техзадание.pdf                        │
│ • план_офиса.docx                       │
└─────────────────────────────────────────┘
```

### Примеры профилей:

| Название | Описание | Параметры |
|----------|----------|-----------|
| Интернет-канал 100 Мбит/с | Запрос для офиса | Скорость, протокол, SLA |
| Виртуальная АТС на 50 номеров | Телефония для call-центра | Каналы, запись, IVR |
| Выделенная линия 1 Гбит/с | Аренда для ЦОД | Скорость, оптика, резервирование |

### Как использовать:

1. **Создайте шаблонный профиль** для типовой услуги
2. **Копируйте и редактируйте** для новых запросов
3. **Добавляйте вложения** (ТЗ, схемы, требования)
4. **Используйте Q&A** для автоматизации через LLM

## Контакты поставщиков

### Что это?

Список email-адресов поставщиков телеком-услуг.

### Поддержка форматов:

- **CSV** — универсальный формат
- **XLSX** — Excel файлы

### Структура CSV:

```csv
email,company,contact_person,notes
sales@telecom.ru,ООО Телеком,Иванов И.И.,Основной поставщик
info@netgroup.ru,АО НетГрупп,Петрова А.С.,Только корпоративным
kp@biznet.ru,БИЗНЕТ Связь,Сидоров П.И.,Работаем с 2020
```

### Поля:

| Поле | Обязательное | Описание |
|------|--------------|----------|
| email | ✅ | Email для отправки |
| company | ✅ | Название компании |
| contact_person | ❌ | Контактное лицо |
| notes | ❌ | Заметки |

### Импорт из CSV:

1. **Подготовьте файл** с колонками: email, company, contact_person
2. **Откройте приложение** → вкладка **👥 Контакты**
3. **Нажмите** **📥 Импорт**
4. **Выберите файл** (CSV или XLSX)
5. **Настройте колонки** (сопоставьте поля)
6. **Проверьте предпросмотр**
7. **Нажмите** **📥 Импортировать**

### Дедупликация:

- Контакты с одинаковым email **не дублируются**
- При импорте **обновляются** существующие записи
- Можно проверить дубли **вручную** перед импортом

### Примеры использования:

**Вариант 1: Из Excel**
```
export contacts.xlsx → Импорт → 50 контактов за 1 минуту
```

**Вариант 2: Из CRM**
```
CRM export CSV → Импорт → 500 контактов за 5 минут
```

**Вариант 3: Из почты**
```
Почта → Export → Импорт → База поставщиков
```

## Шаблоны писем

### Что это?

Готовые шаблоны писем для запроса КП с автоматической заменой переменных.

### Переменные:

| Переменная | Описание | Пример |
|------------|----------|--------|
| `{{ company }}` | Название компании поставщика | ООО Телеком |
| `{{ service_name }}` | Название услуги | Интернет-канал 100 Мбит/с |
| `{{ operator_name }}` | Ваша компания | ООО Вектор |
| `{{ contact_person }}` | Контактное лицо | Иванов И.И. |
| `{{ request_date }}` | Дата запроса | 20.05.2026 |

### Типы шаблонов:

1. **Первичный запрос** — первое письмо поставщику
2. **Напоминание 1** — через 3 дня без ответа
3. **Напоминание 2** — через 7 дней без ответа
4. **Уточнение** — запрос дополнительных деталей
5. **Сравнение** — запрос уточнённых условий

### Пример шаблона:

**Тема:**
```
Запрос КП - {{ service_name }}
```

**Текст (Plain):**
```
Добрый день, {{ contact_person }}!

Наша компания {{ operator_name }} запрашивает коммерческое предложение на:

{{ service_name }}

Просим предоставить:
1. Стоимость
2. Сроки подключения
3. Технические требования

С уважением,
{{ operator_name }}
```

**Текст (HTML):**
```html
<html>
<body>
<p>Добрый день, <strong>{{ contact_person }}</strong>!</p>

<p>Наша компания <strong>{{ operator_name }}</strong> запрашивает коммерческое предложение на:</p>

<p><em>{{ service_name }}</em></p>

<p>Просим предоставить:</p>
<ol>
  <li>Стоимость</li>
  <li>Сроки подключения</li>
  <li>Технические требования</li>
</ol>

<p>С уважением,<br>
{{ operator_name }}</p>
</body>
</html>
```

### Как создать шаблон:

1. Перейдите во вкладку **📝 Шаблоны**
2. Нажмите **➕ Создать**
3. Заполните:
   - **Название** — внутреннее имя шаблона
   - **Тип** — первичный/напоминание/уточнение
   - **Тема** — тема письма (можно с переменными)
   - **Текст Plain** — текстовая версия
   - **Текст HTML** — HTML версия (опционально)
   - **Вложения** — документы (опционально)
4. Нажмите **👁️ Предпросмотр** — проверьте замену переменных
5. Нажмите **💾 Сохранить**

### Предпросмотр:

При нажатии **👁️ Предпросмотр** приложение:
- Подставит **демо-данные** в переменные
- Покажет, как будет выглядеть письмо
- Проверит корректность всех переменных

## Генерация писем через LLM (v2.1) ✨

### Что это?

Автоматическая генерация персонализированных писем через Large Language Models (LLM) на основе профиля закупки и контекста диалога.

**Доступно в версии 2.1+**

### Возможности:

| Тип письма | Описание | Когда использовать |
|------------|----------|-------------------|
| **Первичное письмо** | Генерация запроса КП на основе профиля | При создании новой рассылки |
| **Напоминание 1** | Вежливое напоминание (3 дня без ответа) | Если нет ответа 3 дня |
| **Напоминание 2** | Настойчивое напоминание (7 дней без ответа) | Если нет ответа 7 дней |
| **Follow-up** | Уточнение деталей, запрос дополнительной информации | При необходимости уточнить детали КП |

### Как использовать в мастере рассылки:

**Шаг 1: Создайте профиль**
- Заполните название, описание, технические параметры
- Укажите требования (бюджет, сроки)

**Шаг 2: Откройте мастер рассылки**
- Нажмите **📧 Создать рассылку**
- Выберите профиль на Шаге 1

**Шаг 3: Нажмите "✨ Сгенерировать через LLM"**
- Кнопка активна после выбора профиля
- Генерация происходит в фоновом режиме (~5-10 секунд)

**Шаг 4: Предпросмотр и редактирование**
Откроется диалог с 4 вкладками:
- **📝 Тема** — тема письма (редактируемая)
- **📄 Текст (Plain)** — текстовая версия
- **🌐 HTML** — HTML версия
- **👁️ Предпросмотр** — как будет выглядеть письмо

**Шаг 5: Действия в диалоге**
- **✨ Перегенерировать** — создать новый вариант (если не понравился)
- **📋 Копировать текст** — скопировать в буфер обмена
- **💾 Применить** — использовать сгенерированное письмо как шаблон
- **✖ Отмена** — закрыть без применения

### Преимущества LLM генерации:

✅ **Персонализация** — письмо адаптируется под профиль и контакт  
✅ **Экономия времени** — не нужно писать шаблон вручную  
✅ **Профессиональный тон** — LLM пишет в деловом стиле  
✅ **Учёт контекста** — используются технические параметры из профиля  
✅ **Fallback** — при ошибке LLM используется шаблон

### Примеры использования:

**Сценарий 1: Первичная рассылка**
```
1. Профиль: "Интернет-канал 100 Мбит/с"
2. Контакты: 50 поставщиков
3. Нажать "Сгенерировать через LLM"
4. Применить сгенерированный шаблон
5. Запустить рассылку
```

**Сценарий 2: Напоминание**
```
1. Диалог без ответа 3 дня
2. Открыть диалог
3. Нажать "Сгенерировать напоминание"
4. Проверить и отправить
```

**Сценарий 3: Follow-up**
```
1. Получено КП, нужны уточнения
2. Открыть диалог
3. Нажать "Сгенерировать follow-up"
4. Указать цель: "Уточнить сроки подключения"
5. Отправить
```

### Настройки:

**Rate limiting** (автоматически):
- 60 запросов в минуту (RPM)
- 1000 запросов в час (RPH)
- 10000 токенов в минуту (TPM)
- 100000 токенов в день (TPD)

**Аудит логирование** (автоматически):
- Все генерации записываются в Audit Logs
- Успешные и ошибочные попытки
- Детали: профиль, контакт, результат

### Обработка ошибок:

| Ошибка | Действие системы |
|--------|-----------------|
| LLM недоступен | Fallback на шаблон |
| Таймаут API | Retry (3 попытки) |
| Пустой ответ | Повторная генерация |
| Некорректный формат | Fallback на минимальный шаблон |

### Советы по использованию:

💡 **Качество профиля влияет на качество письма**  
Чем подробнее заполнен профиль, тем точнее будет сгенерированное письмо.

💡 **Проверяйте перед отправкой**  
Всегда используйте предпросмотр перед применением сгенерированного текста.

💡 **Перегенерируйте при необходимости**  
Если первый вариант не понравился — нажмите "Перегенерировать".

💡 **Сохраняйте удачные шаблоны**  
После применения удачного сгенерированного письма сохраните его как шаблон для будущего использования.

### Ограничения:

- Требуется настроенный LLM сервис (ProxyAPI или другой)
- Генерация занимает 5-10 секунд
- Может потребоваться редактирование результата
- Не подходит для очень специфичных требований (лучше ручной шаблон)

### Интеграция с другими функциями:

**Массовая отправка:** Сгенерированное письмо можно использовать как шаблон для рассылки.

**Напоминания:** Автоматическая генерация напоминаний для диалогов без ответа.

**Rule Engine:** Правила могут триггерить генерацию follow-up писем.

**Аудит:** Все генерации логируются для отслеживания.

## Настройка SMTP/IMAP

### Что это?

Настройки email-аккаунта для отправки и получения писем.

### Поддержка провайдеров:

| Провайдер | SMTP | IMAP | Особенности |
|-----------|------|------|-------------|

## Массовая отправка

### Что это?

Отправка писем всем контактам из базы с контролем частоты и лимитов.

### Процесс:

```
1. Выбор профиля и шаблона
   ↓
2. Выбор контактов (все или выборочно)
   ↓
3. Настройка задержек (5-30 сек)
   ↓
4. Настройка лимитов (в час/в день)
   ↓
5. Запуск рассылки
   ↓
6. Мониторинг прогресса
   ↓
7. Логирование результатов
```

### Настройки:

| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| Задержка между письмами | 5-30 сек | Случайная задержка для каждого письма |
| Retry при ошибке | 3 попытки | Exponential backoff (1с, 2с, 4с) |
| Ограничение в час | 100 писем | Чтобы не заблокировали |
| Ограничение в день | 500 писем | Суточный лимит |
| Пауза/отмена | ✅ | В любой момент |

### Как запустить:

1. Нажмите **📧 Создать рассылку**
2. **Шаг 1:** Выберите профиль и шаблон
3. **Шаг 2:** Выберите контакты (чекбоксы или "Все")
4. **Шаг 3:** Настройте задержки и лимиты
5. **Шаг 4:** Проверьте сводку и нажмите **🚀 Запустить**

### Мониторинг:

Во время отправки отображается:
- **Прогресс-бар** — сколько отправлено из общего числа
- **Статистика** — успешно / ошибки / осталось
- **Текущий контакт** — кому отправляем прямо сейчас
- **Лог** — все операции в реальном времени
- **Кнопки** — Пауза, Отмена

### Пауза и возобновление:

- **Пауза** — остановит текущую отправку, но сохранит прогресс
- **Возобновление** — продолжит с места остановки
- **Отмена** — полностью отменит рассылку

### Статусы рассылки:

| Статус | Описание |
|--------|----------|
| draft | Черновик, не запущена |
| queued | В очереди на отправку |
| sending | Отправка идёт |
| paused | На паузе |
| completed | Завершена успешно |
| cancelled | Отменена пользователем |

## Приём и обработка ответов

### Что это?

Автоматический сбор писем из почты, классификация ответов и создание задач.

### Процесс:

```
1. Проверка IMAP (ручная или автоматическая)
   ↓
2. Получение новых писем
   ↓
3. Дедупликация по Message-ID
   ↓
4. Email threading (In-Reply-To, References)
   ↓
5. LLM-классификация (с fallback на keywords)
   ↓
6. Парсинг вложений (PDF/Excel/Word)
   ↓
7. Привязка к диалогу или создание нового
   ↓
8. Автоматическое создание задач
   ↓
9. Применение правил Rule Engine
```

### Классификация ответов:

| Тип | Описание | Действие |
|-----|----------|----------|
| **kp** | Коммерческое предложение | Сохранить данные, создать задачу "Анализ КП" (высокий приоритет) |
| **question** | Вопрос от поставщика | Создать задачу "Ответить" (средний приоритет) |
| **refusal** | Отказ от сотрудничества | Архивировать диалог |
| **auto_reply** | Автоответчик (вне офиса) | Отложить на 3 дня |
| **spam** | Рекламные/нежелательные | Пометить, опционально удалить |
| **unknown** | Не классифицируется | Создать задачу "Проверить вручную" |

### LLM-классификация:

**Модель:** gpt-5.4-mini через ProxyAPI  
**Уверенность:** > 0.5 → использовать LLM, ≤ 0.5 → fallback на ключевые слова  
**Rate limiting:** RPM, RPH, TPM, TPD лимиты для защиты API

### Парсинг вложений:

**Поддерживаемые форматы:**
- **PDF** — pdfplumber (таблицы + текст)
- **Excel** — pandas/openpyxl (автоматическое определение колонок)
- **Word** — python-docx (таблицы + параграфы)

**Извлекаемые данные:**
- Цены (услуга, цена, валюта)
- Сроки подключения
- Условия (оплата, гарантия, SLA)
- Контактные данные менеджера

**Лимит:** 50MB на вложение

### Email threading:

Автоматическое связывание писем в цепочки:
1. Проверка `In-Reply-To` — поиск родительского сообщения
2. Проверка `References` — полная цепочка
3. Fallback по `Subject` (без Re:/Fwd:)

### Дедупликация:

Проверка `Message-ID` перед обработкой письма — защита от дубликатов при повторной проверке почты.

### Автоматические правила (Rule Engine):

**Правила по умолчанию:**

1. **КП получено** → создать задачу + сгенерировать черновик ответа
2. **Отказ** → архивировать диалог
3. **Вопрос** → создать задачу + сгенерировать черновик
4. **Спам** → пометить для проверки
5. **Благодарность** → автоответ (отключено по умолчанию)

**Настройка правил:**
- Меню → Инструменты → Правила обработки
- Визуальный редактор условий и действий
- Приоритеты правил
- Включение/отключение правил

### Настройка автоматической проверки:

1. Перейдите во вкладку **⚙️ Настройки**
2. Включите **Автоматическая проверка почты**
3. Настройте **интервал** (по умолчанию 1 час)
4. Выберите **аккаунт** для проверки

**Или используйте планировщик:**
- Меню → Инструменты → Настройки планировщика
- Включите фоновую проверку
- Настройте время daily cleanup (по умолчанию 2:00 ночи)

### Ручная проверка:

Нажмите **📬 Проверить почту** в главном окне.

## Частые вопросы

### Q: Как создать первое КП?
**A:** 
1. Создайте профиль → импортируйте контакты → создайте шаблон
2. Настройте SMTP → запустите рассылку
3. Дождитесь ответов → проверьте почту
4. LLM классифицирует ответы → КП сохранятся автоматически

### Q: Как удалить профиль?
**A:** Профиль нельзя удалить, только пометить неактивным (чекбокс "Активный" во вкладке Профили). Данные сохраняются.

### Q: Как восстановить удалённый контакт?
**A:** Контакты не удаляются, только помечаются неактивными. Отфильтруйте "Неактивные" и включите чекбокс.

### Q: Сколько контактов можно импортировать за раз?
**A:** Теоретически без ограничений. Практически рекомендуется до 1000 за один импорт для скорости.

### Q: Можно ли использовать несколько SMTP аккаунтов?
**A:** Да, можно добавить сколько угодно. Один из них можно отметить как основной для отправки.

### Q: Как работает шифрование паролей?
**A:** Используется Fernet (symmetric encryption). Ключ хранится в Windows Credential Manager. Пароли никогда не сохраняются в открытом виде.

### Q: Где хранятся данные?
**A:** В SQLite базе данных: `data/spam_kp_assistant.db`

### Q: Как сделать резервную копию?
**A:** 
1. Меню → Файл → Экспорт данных (JSON/XML)
2. Или скопируйте файл `spam_kp_assistant.db` в безопасное место

### Q: Как восстановить из резервной копии?
**A:** 
1. Меню → Файл → Импорт данных
2. Или замените текущий файл БД на резервную копию

### Q: Что делать, если окно не открывается?
**A:** 
1. Проверьте логи: `data/app.log`
2. Попробуйте консольный режим: `python console_app.py`
3. Проверьте зависимости: `pip install -r requirements.txt`
4. Используйте `pythonw run.py` вместо `python run.py` (для PowerShell)

### Q: Как настроить автоматическую проверку почты?
**A:** 
1. Меню → Инструменты → Настройки планировщика
2. Включите "Фоновая проверка почты"
3. Настройте интервал (по умолчанию 1 час)

### Q: Как работают напоминания?
**A:** 
1. Напоминание 1 — через 3 дня без ответа
2. Напоминание 2 — через 7 дней без ответа
3. Максимум 2 напоминания одному контакту
4. Шаблоны можно настроить: Меню → Инструменты → Шаблоны напоминаний

### Q: Как настроить Rule Engine (правила)?
**A:** 
1. Меню → Инструменты → Правила обработки
2. Нажмите "➕ Добавить правило"
3. Задайте условия (ключевые слова, тип сообщения, вложения)
4. Задайте действия (создать задачу, отправить ответ, обновить статус)
5. Сохраните и активируйте

### Q: Как сравнить несколько КП?
**A:** 
1. Меню → Инструменты → Сравнение КП
2. Выберите диалоги с КП
3. Таблица покажет цены, сроки, условия от всех поставщиков
4. Экспортируйте в Excel для детального анализа

### Q: Как посмотреть аналитику?
**A:** 
1. Меню → Инструменты → Отчёты
2. Дашборд покажет: количество КП, средние цены, timeline ответов
3. Экспортируйте в CSV для отчётов

### Q: Что такое email threading?
**A:** Автоматическое связывание писем в цепочки переписки по In-Reply-To и References заголовкам. Все сообщения одного диалога группируются.

### Q: Что делать, если LLM недоступен?
**A:** Система автоматически переключится на keyword-based классификацию. Функционал не теряется, только точность классификации.

### Q: Как ограничить размер вложений?
**A:** По умолчанию лимит 50MB. Настройка в `config.py` или через переменную окружения `MAX_ATTACHMENT_SIZE_MB`.

### Q: Как настроить автоочистку старых данных?
**A:** 
1. По умолчанию: удаление данных старше 90 дней
2. Настройка: `services/scheduler_service.py` → `setup_cleanup_job(days=90)`
3. Запускается ежедневно в 2:00 ночи

### Q: Как работает Retry с exponential backoff?
**A:** При ошибке отправки письма:
- 1 попытка — сразу
- 2 попытка — через 1 секунду
- 3 попытка — через 2 секунды
После 3 неудач письмо помечается как ошибка.

### Q: Как настроить Rate limiting для LLM?
**A:** 
- RPM (requests per minute): по умолчанию 60
- RPH (requests per hour): по умолчанию 1000
- TPM (tokens per minute): по умолчанию 10000
Настройка в `config.py` или через `.env`

### Q: Где посмотреть историю действий?
**A:** Меню → Инструменты → Аудит (Audit Logs). Показывает все операции: создание, изменение, удаление с метками времени и автором.
