## 🔐 Рекомендации

### Для разработчиков:

1. **Никогда не коммить `.env`**
   - Файл уже в `.gitignore`
   - Проверяй `git status` перед коммитом

2. **Используй `.env.example`**
   - Создай шаблон без секретов
   - Коммить только шаблон

3. **Шифруй пароли**
   - Используй `utils/encryption.py`
   - Храни в Credential Manager (Windows) или Keychain (macOS)

4. **Проверяй историю Git**
   - Если секрет уже закоммичен — удали из истории:
   ```bash
   git filter-branch --force --index-filter \
     "git rm --cached --ignore-unmatch PATH_TO_SECRET_FILE" \
     --prune-empty --tag-name-filter cat -- --all
   ```

5. **Регулярно проводи аудит**
   - Используй `git-secrets` или `truffleHog`
   - Проверяй перед каждым релизом
